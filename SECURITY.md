# Security Policy

Thank you for helping keep Zaino secure!

## Reporting Security Issues

Security is essential to Zaino. We appreciate the work of security researchers acting in good faith to identify and responsibly report potential vulnerabilities, helping us maintain strong privacy and security standards for our users and technology.

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Louay0007/zaino-cli/security/advisories/new). Do not open a public issue for a suspected vulnerability.

## Vulnerability Disclosure Program

We ask that you give us a reasonable window to investigate and ship a fix before any public disclosure. We will credit reporters who wish to be named once a fix is released.

## How to operate Zaino safely

For details on Zaino security boundaries, including sandboxing, approvals, and network controls, run `zaino --help` for the sandbox and approval flags, or see [configuration](docs/config.md).
